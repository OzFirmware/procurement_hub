Why the blocks are different sizes

Three sizes, three reasons. 4×3 — money is outstanding, so there is something to decide; the block has room for the currency breakdown. 3×2 — real purchase history, nothing owed; the figure is enough. 3×1 — registered but never used; the honest content is the vendor name and the word “none”, and padding that to card height would be a lie about how much there is to know. Alphabetical order is available in the sort control, but it is not the default, because alphabetical order tells an approver nothing.
